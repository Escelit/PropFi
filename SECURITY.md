# Security Policy

## Supported Versions

We currently support the following versions of PropFi:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of PropFi seriously. If you believe you have found a security vulnerability, please report it to us as follows:

1. **Email us**: Send an email to [security@propfi.xyz](mailto:security@propfi.xyz).
2. **Do not open an issue**: Please do not report security vulnerabilities via public GitHub issues.

### What to include in your report

Please include as much information as possible to help us reproduce and fix the issue:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.
- Any suggested fixes or mitigations.

### Our Response Process

1. We will acknowledge receipt of your report within 48 hours.
2. We will investigate the issue and determine its severity.
3. We will work on a fix and provide updates as we progress.
4. Once the fix is ready, we will coordinate a public disclosure.

## Disclosure Policy

We follow a responsible disclosure policy. We ask that you give us a reasonable amount of time to fix the issue before making it public. In return, we will work with you to ensure that your contribution is recognized.

---

**Note**: PropFi is currently in alpha/beta. Use on mainnet with real funds is at your own risk.
